Details
How the edits were made and checked

Qwen-Image-2.1-Turbo (revision d65dbc9a), 8 steps, 1024 × 768, one fixed prompt per gap type plus the same instruction to keep everything else unchanged. Each edit was resized to 768 × 576, then audited blind by both models and segmented. Other features changed state 2.55 times per edit on average, against 0.68 expected from the small model's run-to-run instability; some are intended side effects (trees bring shade). Pixels changed in classes the edit should not touch: median 1.6%, 90th percentile 9.9%.
